# Rita's Kitchen — Frontend Demo

A frontend-only reconstruction of the premium Rita's Kitchen restaurant experience.

## What is included
- Next.js App Router + TypeScript
- Tailwind CSS v4
- Framer Motion reveal animations
- Lenis smooth scrolling
- Recharts analytics dashboard
- Full restaurant menu catalogue
- Local cart state using localStorage
- Checkout UX (no payment integration)
- Customer account/login/signup UI (no auth backend)
- Order tracking UI
- Delivery monitoring UI
- Operations dashboard with mock data

## Deliberately excluded
- Supabase
- API routes
- Databases
- Authentication providers
- Real payment gateway
- Real delivery GPS/network APIs
- Server actions / backend persistence

## Run
```bash
npm install
npm run dev
```

Then open http://localhost:3000.
